# Data-Cleaning-Reporting-Automation

## Overview
This project automates data cleaning and reporting using Python.

## Features
- Removes duplicate records
- Handles missing values
- Standardizes column names
- Generates summary statistics
- Creates sales charts
- Exports cleaned data and reports

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- ReportLab

## Run

```bash
pip install -r requirements.txt
python src/main.py
```

## Output
- Cleaned CSV
- Excel summary report
- Sales chart
